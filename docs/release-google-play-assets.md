# Google Playストアアセット準備ガイド（Issue #15）

Google Play Console 申請時に必要なアセットを、実機撮影・デザイン作業の手順として整理する。

## 保存先（推奨）

```
app/assets/store-listing/
  icon-512.png
  feature-graphic-1024x500.png
  screenshots/
    phone-ja-01.png
    phone-ja-02.png
    phone-ja-03.png
```

## 必須アセット

- スクリーンショット（最低2枚、推奨6枚）
  - 1080x1920 以上、16:9〜9:20
- フィーチャーグラフィック
  - 1024x500
  - PNG（24bit）または JPEG
  - アルファチャンネル不可
- ストアアイコン
  - 512x512 PNG
  - アルファチャンネル不可

## 推奨スクリーンショット構成

1. 初期画面（画像未選択）
2. 画像選択後（BEFORE表示）
3. ガビガビ変換後（BEFORE/AFTER）
4. テンプレート選択UI
5. Discord圧縮導線
6. 動画変換画面

## ストア説明文（日本語）

### 短い説明（80文字以内）

写真や動画を意図的にガビガビにしたり、指定したサイズに圧縮・変換できます。

### 詳細説明

GabiGabi（ガビガビ）は、画像や動画を素早く変換・圧縮・劣化させるためのツールアプリです。

- 意図的な劣化（ガビガビ化）を5段階で調整
- 目標サイズ指定（例: 10MB以内）で圧縮
- 画像/動画の複数フォーマットに対応
- 処理は端末内で完結（ローカル処理）

## 進捗チェックリスト

- [ ] 実機スクリーンショットを2枚以上用意
- [ ] フィーチャーグラフィック（1024x500）を作成
- [ ] ストアアイコン（512x512）を最終版に差し替え
- [ ] 短い説明/詳細説明を Play Console へ転記

## 完了条件

- 上記アセットが `app/assets/store-listing/` に配置されている
- Play Console の「ストア掲載情報」入力が完了している
